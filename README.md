\# My Agent



A simple AI agent I built in Python. It runs on my own laptop using Ollama and the Llama 3.2 model.



\## What it can do



\- Remembers past chats (memory.json)

\- Tells the time and adds numbers

\- Saves and reads notes

\- Reads and writes text files

\- Asks "Allow? y/n" before writing any file

\- Keeps a log of every tool it uses (log.txt)

\- Does big jobs one step at a time



\## How to run it



1\. Install Python and Ollama

2\. Run: ollama pull llama3.2

3\. Run: pip install ollama

4\. Run: python agent.py

5\. Type "bye" to stop



\## What I learned



Small models sometimes say they did something when they didn't. The approval check and the log in my code show what really happened.
